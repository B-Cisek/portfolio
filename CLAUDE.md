# CLAUDE.md

This file provides guidance to AI Agents when working with code in this repository.

## Common Development Commands

### Development Server
- `pnpm run dev` - Start development server

### Build and Deployment
- `pnpm run build` - Build the Astro application for production
- `pnpm run preview` - Preview the built application locally

### Code Quality
- `pnpm run lint` - Lint and fix code quality issues
- `pnpm run lint:check` - Check code quality without fixing
- `pnpm run format` - Format code using Prettier
- `pnpm run format:check` - Check code formatting without fixing

## Architecture Overview

### Technology Stack
- Astro 6
- Tailwind CSS 4
- React 19
